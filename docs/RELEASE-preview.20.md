# 番茄农场 preview.20：近日行动与应用内更新

生成今日番茄现在优先读取任务表“近日行动”复选框，按“今日计划番茄数”补齐今天的番茄；已完成、放弃、未勾选或数量为空的任务不生成。旧表没有该字段时继续使用任务计划日。重复生成不重复创建，原记录保留；没有符合条件的任务会明确提示，不再误报“已齐全”。设置中的原番茄表日期字段仍保持“计划日”。

右上角设置新增“软件更新”：检查更新 → 下载更新并重启。下载显示进度和大小，校验成功后安装并自动重启。有正在计时、暂停或等待确认的专注时，先处理完当前番茄，再点击安装；不会静默中断计时。检查不会自动下载，关闭 App 不会自动安装。

**首次升级**：preview.19 及更早版本先从托盘退出旧版，下载并运行本 Release 的 `setup.exe`。桌面“番茄农场”入口会指向固定安装位置，沿用原连接与历史。之后用 App 内更新即可。保留 portable 供直接体验；portable 的下一次应用内更新会转为固定安装，旧 EXE 不自动删除。

Windows x64 预览版；安装包未签名。更新采用 electron-updater 6.8.3 官方 NSIS 流程、固定 GitHub preview 通道及 SHA-512 下载完整性校验。附 portable、setup、blockmap、preview.yml 和 SHA256SUMS.txt。无需新增飞书应用、服务器或 GitHub token。

验收：88 项逻辑／飞书模拟测试；真实飞书选中 5 项生成 16 行、重复生成 0 行，已有 18 条历史保持不变；独立 NSIS 安装环境通过真实下载、界面进度、活动专注保护、安装重启及历史保留；HTTP 404／错误 SHA-512 阻止安装。完整证据见 docs/ACCEPTANCE-planning-updates.md。
