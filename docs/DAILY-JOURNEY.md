# 每日番茄旅程

“今日旅程”在概览两张今日数字卡下方，占概览整列宽度。番茄和休息图案串在同一条横线上；时间放在番茄角标，不独占时间轴。默认16个番茄：8点4→吃饭/小憩；12点3→小憩；3→小憩/健身/吃饭/小憩；20点3→小憩；3→小憩/下班睡觉，结束参照24点。未指定钟点留空；参考时间不会自动开始或结束任务。

旅程右上角“设置”打开可视化模板。可复制新建、从当前旅程新建、命名、编辑每段数量和参考小时、用图标添加或移除休息节点、上移或移除阶段，预览随编辑变化。先保存，再应用到当前查看的今日或明日。默认模板用于未来尚未安排的新日，已有当天安排不会自动覆盖。多个模板按任务来源保存，最多12个模板、20段、100个番茄；模板只保存安排，不复制任务或完成记录。

点击每个轮廓分别选择现有任务，或保留自由番茄。明天按钮可提前安排次日，再点今天回到当前旅程。预设按当前飞书来源和本地日期保存；只存在这台电脑的App本地存储，不声称跨机同步。任务关联保存稳定任务编号，次日使用当天的可用番茄；如果当天还没有这个任务的番茄，点击“生成今日番茄”或重新选任务，不会自动用别的任务替代。

App跨午夜持续打开时，旅程不会启动昨日任务行；先点击“生成今日番茄”刷新当日任务，再开始预设。新进程启动已读取当天任务，不需要额外刷新。

拖动未完成轮廓到另一段，任务随轮廓移动，今日总数量不变；也可以点击轮廓，用“移动到”下拉完成调整。已确认完成和进行中的番茄不移动、不移除。应用模板保留仍存在的关联任务与实际完成；若缩掉已完成或关联任务的番茄会拒绝，请先移动或解除关联。当前有未结束番茄时不能应用今日模板，仍可安排明天。

开始使用既有计时器。进行中的轮廓显示琥珀色，点击它可更换当前任务；实际用时和会话编号不变。结束确认后，依据原专注记录的完成数量填色；放弃或确认0个不填。今日已完成的原记录也会依顺序填入轮廓，多数量记录按单个单位关联一次，不复制历史。数量修正仍以原记录为准。

旅程标题右侧空碗、ZZZ和哑铃记录实际吃饭、小憩、健身，按钮带边框和蓝色选中状态。点击选择“去吃饭／吃完了”“去睡觉／睡醒了”“去健身／练完了”；进行中在原按钮显示正计时。先保存开始再暂停已有专注，下一项实际休息或开始/继续专注自动结束上一项。明确结束只结束记录，不自动恢复专注；保存、暂停或恢复失败保持原记录并可重试。

实际记录的旅程图标以绿色填色/浅底点亮，进行中为蓝色高亮，未来预设保持灰色轮廓；小憩ZZZ也会填实。右侧三个入口显示当天最近同类实际记录的状态，进行中保留正计时，已结束保持绿色，悬浮可看最近起止和时长。补记同样点亮，重启从原记录恢复；明日预设不继承今日点亮。不增加计时器、动画或存储写入。

没先点击“去”而直接点击“结束”，会打开小型补记表单。默认上一个同来源专注或实际休息的结束时间至现在，开始和结束都可手调，时长随起止计算；原始毫秒边界在未编辑时保留，避免秒级显示产生重叠。没有上一结束时间时要求填写实际开始；有其他进行中休息须先结束，正在专注须先暂停或确认。补记拒绝未来、倒置或与已记录专注/休息重叠的时段，正常暂停间隙与跨午夜可保存；不改原专注记录或番茄数。

第一次实际吃饭替代第一个预设碗，第二次替代第二个，小憩同样按顺序匹配；图标移到点击时当天实际已完成数量之后，不要求按预设阶段操作。未完成轮廓和未触发休息都保留，额外休息仍可记录。悬浮实际图标查看起止时间、时长和番茄数量位置。记录仅本机按任务来源保存，换日保留历史，不上传飞书、不增加番茄数；旧版会忽略独立休息键，不改原专注数据。当前最多2048条，达到上限保留原内容并提示。

哑铃复用实际健身记录，月亮保留原下班睡觉节点。科学专注提醒使用蓝色描边，当前阶段存在未经过的健身节点时提供“去健身”，并记录实际开始；已被实际记录替代的健身预设不重复进入。去睡觉开启实际小憩。没有强制钟点或阶段鼓励；自设每日番茄目标/提醒间隔/网站额度保持原值。

健身与补记使用休息v2独立键：新键不存在时只读旧v1吃饭/小憩，首次事件变化保存到v2，v1原字节保持不动，旧App可继续读v1；原专注数据不迁移。新旧坏/空数据保留并提示，不自动清空。补记图标按开始时的实际番茄数插入，三类同类预设仍依序匹配。

累计进度条移到农场标题旁边，每100个番茄一段、25个一面小旗，282显示200–300；总量和其他农场里程碑不变。实际休息正计时仅在今日旅程可见且有进行中休息时用一个每秒UI更新，隐藏、查看明日或卸载时清理，无新进程、逐秒写盘或网络请求；休息存储只在事件变化时写。健身可用性通过原进度通道传递当前日boolean。坏数据保留原内容并显示错误；保存失败不会假称成功或启动未关联计时。原专注历史使用原存储，回退旧版仍可读取。
