# 每日番茄旅程

“今日旅程”在概览的“今日番茄”下方，同列同宽。默认4/3/3/3/3个轮廓，依次接吃饭/睡觉、睡觉、健身/吃饭/睡觉、睡觉、下班。设置可分别修改数量、休息名称、阶段顺序；这些是接续顺序，不是钟点要求。

点击每个轮廓分别选择现有任务，或保留自由番茄。明天按钮可提前安排次日，再点今天回到当前旅程。预设按当前飞书来源和本地日期保存；只存在这台电脑的App本地存储，不声称跨机同步。任务关联保存稳定任务编号，次日使用当天的可用番茄；如果当天还没有这个任务的番茄，点击“生成今日番茄”或重新选任务，不会自动用别的任务替代。

拖动未完成轮廓到另一段，任务随轮廓移动，今日总数量不变；也可以点击轮廓，用“移动到”下拉完成调整。已确认完成和进行中的番茄不移动、不移除。设置减少数量时，优先移除末尾未完成轮廓，保留实际成果。

开始使用既有计时器。进行中的轮廓显示琥珀色，点击它可更换当前任务；实际用时和会话编号不变。结束确认后，依据原专注记录的完成数量填色；放弃或确认0个不填。今日已完成的原记录也会依顺序填入轮廓，多数量记录按单个单位关联一次，不复制历史。数量修正仍以原记录为准。

休息节点可手动进入、继续；若已有计时会先暂停，继续时复用现有恢复操作。没有新休息倒计时、强制钟点或阶段鼓励。科学专注的自设每日番茄目标/提醒间隔/网站额度保持原值，不因旅程默认16个自动改变。

概览旗路以50个番茄为一段，282显示250–300；总量和其他农场里程碑不变。旅程新增内容没有计时循环或新进程，只在安排和专注记录变化时保存。坏数据保留原内容并显示错误；保存失败不会假称成功或启动未关联计时。原专注历史使用原存储，回退旧版仍可读取。
