# 每日番茄旅程

“今日旅程”在概览两张今日数字卡下方，占概览整列宽度。番茄和休息图案串在同一条横线上；时间放在番茄角标，不独占时间轴。默认16个番茄：8点4→吃饭/小憩；12点3→小憩；3→小憩/健身/吃饭/小憩；20点3→小憩；3→小憩/下班睡觉，结束参照24点。未指定钟点留空；参考时间不会自动开始或结束任务。

旅程右上角“设置”打开可视化模板。可复制新建、从当前旅程新建、命名、编辑每段数量和参考小时、用图标添加或移除休息节点、上移或移除阶段，预览随编辑变化。先保存，再应用到当前查看的今日或明日。默认模板用于未来尚未安排的新日，已有当天安排不会自动覆盖。多个模板按任务来源保存，最多12个模板、20段、100个番茄；模板只保存安排，不复制任务或完成记录。

点击每个轮廓分别选择现有任务，或保留自由番茄。明天按钮可提前安排次日，再点今天回到当前旅程。预设按当前飞书来源和本地日期保存；只存在这台电脑的App本地存储，不声称跨机同步。任务关联保存稳定任务编号，次日使用当天的可用番茄；如果当天还没有这个任务的番茄，点击“生成今日番茄”或重新选任务，不会自动用别的任务替代。

App跨午夜持续打开时，旅程不会启动昨日任务行；先点击“生成今日番茄”刷新当日任务，再开始预设。新进程启动已读取当天任务，不需要额外刷新。

拖动未完成轮廓到另一段，任务随轮廓移动，今日总数量不变；也可以点击轮廓，用“移动到”下拉完成调整。已确认完成和进行中的番茄不移动、不移除。应用模板保留仍存在的关联任务与实际完成；若缩掉已完成或关联任务的番茄会拒绝，请先移动或解除关联。当前有未结束番茄时不能应用今日模板，仍可安排明天。

开始使用既有计时器。进行中的轮廓显示琥珀色，点击它可更换当前任务；实际用时和会话编号不变。结束确认后，依据原专注记录的完成数量填色；放弃或确认0个不填。今日已完成的原记录也会依顺序填入轮廓，多数量记录按单个单位关联一次，不复制历史。数量修正仍以原记录为准。

休息节点可手动进入、继续；空碗是吃饭，轮廓ZZZ是小憩，哑铃是健身，月亮是下班睡觉。若已有计时会先暂停，继续时复用现有恢复操作。科学专注提醒使用蓝色描边，当前阶段存在未经过的健身节点时提供“去健身”，点击后暂停原番茄并进入该节点；无健身安排或已结束健身则不显示。保存或暂停失败保留提醒，可重试。没有新休息倒计时、强制钟点或阶段鼓励。科学专注的自设每日番茄目标/提醒间隔/网站额度保持原值，不因旅程默认16个自动改变。

累计进度条移到农场标题旁边，每100个番茄一段、25个一面小旗，282显示200–300；总量和其他农场里程碑不变。旅程新增内容没有计时循环或新进程，只在安排和专注记录变化时保存；健身可用性通过原进度通道传递一个当前日boolean，不每秒请求或写盘。坏数据保留原内容并显示错误；保存失败不会假称成功或启动未关联计时。原专注历史使用原存储，回退旧版仍可读取。
