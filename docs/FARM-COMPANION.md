# 田间伙伴与农场日记

preview.68 起，入口收在农田里的稻草人上。默认不显示常驻横栏；点击稻草人（键盘 Enter / 空格）打开浮动气泡和随手记，点击外部、关闭按钮或 Escape 收起。气泡不改变农田尺寸，窄屏内容可滚动，收起仍保留草稿。自动提醒不抢焦点、不发声，30秒后收起，主动打开的日记不自动关闭。

日记先写入本机，再使用设置中已有的飞书连接同步。普通打开页面只读取；第一次点击“记下来”时，才会在同一个多维表格中创建“农场日记”表。不会改任务、原番茄或专注成果的账目。

## 保存与换机

- 本机键 `pomatez-farm-journal-v1` 保存已记录的内容；草稿单独保存。没有连接时记录的内容仅留本机，不会在以后连接另一张表时静默上传。
- 有连接的记录按该 Base 的连接指纹分组；换机使用同一飞书应用和 Base，即可读取已上传日记。正在输入的草稿不跨机同步。
- 每条日记有固定 UUID。提交、回读和重试始终使用同一 UUID；内容是追加式的，不自动覆盖或合并同 ID 的不同文字。
- 保存失败不清空输入；网络失败保留本机记录并提示“待同步”。再次保存、重新连接/打开看板或点击“同步日记”可尝试同步。没有定时轮询；失败不会持续重试。
- 开始专注可以继续使用。任务看板卸载期间的日记回执仍先合入最新本地内容，重新回到看板时再读取。
- 同名表重复、字段类型不符、UUID 内容冲突或连接变化时停止该条同步，不覆盖已有数据。格式异常的本地日记也不会被清空。

## 飞书表契约

使用已有 bitable v1 表/记录 API。表名必须唯一：`农场日记`，默认视图 `日记与对话`。

| 字段     | 飞书类型  | 内容                                            |
| -------- | --------- | ----------------------------------------------- |
| 日记 ID  | 文本（1） | UUID，固定不变                                  |
| 记录时间 | 日期（5） | 毫秒时间戳                                      |
| 说话人   | 文本（1） | 我 / 澄                                         |
| 内容     | 文本（1） | 1–4000 字，作为纯文本显示                       |
| 回应话题 | 文本（1） | 可选，被回应的留言 UUID 或引导类型，最多 100 字 |

App 只提交说话人“我”。读取可以接受“澄”的留言；这是预留的数据接口，**没有接入澄服务、个人 OAuth 或新的 AI 服务**。未来接入者需要独立获准后使用已有安全身份，在同一个表追加唯一 UUID 的留言；不能把本模块文档当作根系统接入授权。

当天、同一个 Base 中最新的澄留言可以显示为稻草人气泡。夜间和假日的休息引导优先；留言不会变成命令执行，HTML 也只作为文字显示。过期留言保留在日记列表，不作为今天的提醒。

新留言在日记读回后主动弹出一次；同一个 UUID 不重复提醒。返回可见 App 时最多每60秒一次只读刷新，不使用网络轮询，不借此重试失败上传；本地保存、手动同步和重连仍沿用已有同步路径。没有接入真实澄服务，因此不会凭空产生澄的消息。

日记含私人文字：不上传公开仓库，不复制整个 App 数据目录作为跨机同步，也不将凭证写入日记。

## 引导口径

- 晨间：北京时间 08:00–09:30；只累计实际专注分段，暂停时间不计入。跨天分段按实际重叠分钟计算，不根据番茄数推算晨间分钟。
- 休息：23:30–08:00；记录照常保存和统计，不发额外工作奖励。22:00 起开始温和收尾提示。
- 早安（08:00–09:30）、22点收尾、23点睡眠为不同提醒时段；每个时段每日只提示一次，重启/退出专注返回看板不重复弹出。只在可见看板提示；错过的时段不补发。假日早安鼓励安心休息，23点不催工作。提醒已读键按连接分组、只保留最近120个标记，不同步私人草稿。
- 假日：只标记已经核对的 2026 年中国大陆官方放假调休安排；调休上班与放假分开，其他年份不推算法定休息日。假日工作表达感谢并提醒休息，未种番茄显示安心休息，不扣目标。
- 科研目标在总目标之前：科研红色，总目标金色；两个目标仍仅修改本周、独立保存，不改变历史数量。
- 补记分类使用既有项目分类覆盖字段；只给这条成果着色，不改变任务归属、有效分钟或番茄数。
- 成果同步进度按实际写回、归档、回读、刷新阶段显示，百分比表示阶段进度而非网络字节。成功回执并核对完成后才显示收篮动画；失败时保留本机成果和重试入口。
- 稻草人使用现有 SVG、季节和日夜时钟，增加服装和节日小装饰，没有额外声音；系统减少动画偏好会关闭收篮运动。

官方安排：[2026 放假调休通知](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html)。设计参考：[Super Productivity 同步](https://github.com/super-productivity/super-productivity/blob/master/docs/wiki/2.08-Choose-Sync-Backend.md)、[Habitica 休息模式](https://habitica.com/static/faq)；未引入这些产品或依赖。

## 本地验证

`npm run test:focus:all` 验证有效分段、官方日期、追加式日记、模拟 API 幂等与拒写；`node scripts/test-companion-desktop.cjs` 以隐藏静音的真实 Electron/main/preload/renderer 验证交互。所有数据都是合成记录，使用独立测试目录，不读取真实连接，不创建真实飞书表。

回滚旧版时保留日记键和飞书日记表；旧版忽略它们。日记不会写入原有计时状态格式，因此原专注历史兼容。
