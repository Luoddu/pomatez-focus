# 飞书接入与专注看板

## 连接

在飞书开放平台创建企业自建应用，开通多维表格记录读取、新增记录、数据表读取/创建和字段读取权限，发布应用，并给应用授予目标多维表格的访问权限。知识库链接还需要知识库节点读取权限。应用无须接收聊天消息，也不需要个人 OAuth 凭证。

在应用“飞书连接”中输入 App ID、App Secret 和目标 Base/知识库链接。默认读取“专注记录”表中的“计划日”（日期）、“任务”（关联记录）、“已完成”（复选框）字段；字段名称可调整。关联任务表优先使用“任务名称”作为显示名称。

点击“连接并读取”只验证连接和读取任务。点击“初始化专注会话表”会创建下表；如果同名表已存在，只检查字段，不覆盖字段或删除数据。

| 字段                      | 类型     | 含义                                     |
| ------------------------- | -------- | ---------------------------------------- |
| 会话 ID                   | 文本     | 一次专注的固定 UUID，用于去重            |
| 任务                      | 文本     | 开始专注时的任务名称快照                 |
| 计划记录 ID / 任务记录 ID | 文本     | 回溯原计划和关联任务                     |
| 开始时间 / 结束时间       | 日期时间 | 会话起止时刻，二者之差可能包括暂停       |
| 计划分钟                  | 数字     | 最初设置的番茄长度                       |
| 计时分钟                  | 数字     | 扣除暂停、关机与检测到的缺失时段后的计时 |
| 实际分钟                  | 数字     | 用户确认保留的专注时间                   |
| 完成番茄数                | 数字     | 用户手动确认的数量，默认为 0             |
| 专注日期                  | 文本     | 按电脑本地时区，以开始日期归属统计       |
| 记录类型                  | 文本     | 正常记录为“专注”；受控验证记录为“验收”   |

## 同步规则

确认后先保存本地，再同步飞书。断网或权限不足时保留“待同步”，可在“专注记录”点击重试。启动时会尝试已有待同步记录；不在后台高频重试。一次写入使用固定的 `client_token`，重试前查找同一会话 ID，内容一致才视为已同步。重复/冲突记录会显示错误，不覆盖。

完成数与时长分开保存。计时到点不会勾选任务，也不会根据时长换算完成数；原计划中的“已完成”复选框仍由你在飞书管理。同一计划可以有多个专注会话。确认完成数大于 1 不会猜测应该勾选哪几条计划。

切换 Base 后，旧 Base 的待同步记录会被阻止写入新 Base；切回原连接后再重试。当前版本面向一台电脑、一个使用者，不支持多设备同时编辑同一会话。

## 看板配置

在目标多维表格中新增“专注看板”仪表盘，数据源选“专注会话”。每个图表先设共同筛选：**记录类型 等于 专注**，排除验收数据。

| 组件         | 指标与维度                                     | 时间筛选            |
| ------------ | ---------------------------------------------- | ------------------- |
| 今日专注时长 | 对“实际分钟”求和，单位分钟                     | 开始时间为今天      |
| 今日完成番茄 | 对“完成番茄数”求和                             | 开始时间为今天      |
| 本周专注趋势 | X 轴“专注日期”，Y 轴“实际分钟”求和，折线图     | 开始时间为本周      |
| 任务时间分布 | 按“任务”分组，“实际分钟”求和，条形图           | 按需要选择今天/本周 |
| 专注明细     | 任务、开始时间、结束时间、实际分钟、完成番茄数 | 开始时间降序        |

统计实际分钟，不使用“结束时间 − 开始时间”，以免把暂停也统计进去。跨午夜的整次专注暂归属开始日期；本版不把一次会话拆分到两天。

飞书公开 Bitable v1 仪表盘接口提供列表和复制，未提供单个图表从零配置接口。本版准备好数据表和上述配置说明；图表需在飞书界面配置，不调用私有接口。完成配置后，新同步的专注会话会成为图表数据源。
