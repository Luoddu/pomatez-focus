# 飞书接入与专注看板

## 连接与启用

设置入口在右上角齿轮。使用现有企业自建应用和目标多维表格；除读取记录/字段/数据表外，新版需要更新记录、新增记录、新增字段权限。知识库链接还需要节点读取权限。不接收聊天消息，不使用个人 OAuth。

默认读取“专注记录”表的“计划日”（日期）、“任务”（关联）、“已完成”（复选框）。四象限从关联任务表的单选字段读取，留空自动识别四种标签；当前版本对歧义、缺失或未知值归入“不紧急不重要”，不按标题猜测；请在设置中核对象限字段命中情况。

“保存并测试连接”只保存加密配置并读取。“启用原表专注记录”检查原表并补充以下字段；同名不同类型时报错，不覆盖原字段。已有用户升级不必重新输入凭证。

| 新增字段 | 类型 | 含义 |
| --- | --- | --- |
| 实际分钟 | 数字 | 此番茄所有已确认专注累计值，内部按秒累计 |
| 专注日期 | 日期 | 此行最近一次专注的开始时刻 |
| 专注时间段 | 文本 | 每次专注的有效计时时间段，暂停分段；分别列出计时与确认分钟 |
| 专注同步明细 | 文本 | 会话 UUID、累计目标、时段和确认秒数，用于重试去重；可在视图隐藏，不要手改 |

已有“已完成”复选框直接复用。不创建新专注会话表，不改现有视图过滤和分组。

## 使用与同步

- 选择今日番茄后开始，确认页点击“记录番茄”，回写选中的同一行。一次 12 分钟、下次 13 分钟会累计为 25 分钟；确认保存后，累计达到该行目标会勾选该行已完成。用户确认多个番茄时还会回写后续连续序号。暂停不计时间，继续后仍属同一次专注。
- 到点继续记录额外时间；确认时选择是否计入或修改实际分钟。用户可确认多个番茄，按所选任务、日期和连续序号完成对应计划；缺失序号可补建，部分失败单独提示。首次保存确定此行累计目标，后续不会因调整倒计时长度而改变旧目标。
- 不选择任务即可“开始自由专注”，名称为“自由番茄”。确认后在原表新增一行，并关联复用的“自由番茄”任务，计划日取本次开始日期。未满目标的自由番茄也保留记录，可在当天列表中再次选择继续。
- “放弃本次”不保存、不发送。先确认保存本地，再请求同步；失败保留待同步，点击专注记录标题旁“手动同步”（设置中也保留重试入口）。启动时尝试待同步，不高频轮询。
- 相同会话 ID 只累计一次。读回检查成功才标记已同步；已有人工修改的专注列或变更的任务关联会提示冲突，不静默覆盖。不同 Base 的记录禁止混写。
- 升级前已有的已保存、待同步及进行中记录保留旧路径，继续写入原“专注会话”表；不会搬迁或重复计入新列。本地未绑定飞书的旧记录仍仅保留本地。

自由番茄复用一个同名关联任务；存在多个同名任务时提示先解决歧义。新行通过计划日进入原“今日番茄”视图；已完成行可能在该视图的已完成分组中。App 待选区只列今天未完成的行。

## 看板与限制

在飞书中使用“专注记录”作为数据源：按计划日筛选今天，对实际分钟求和；完成番茄用已完成记录计数；按任务或任务象限分组查看投入。专注时间段可在行详情中展开。测试时请使用独立表格，避免将模拟数据计入个人统计。

一行可能跨多次、甚至跨日期专注；实际分钟是整行累计，专注日期是最近一次开始时间。因此按专注日期分组的整行累计不能当作精确逐日时长分摊；精确会话时间仍在 App 专注记录/导出中。旧“专注会话”看板继续保留历史数据，新旧表不自动合并。

本版支持多台电脑轮流使用，换机前同步完成，同一行由本进程串行更新；不承诺多设备/其他写入者同时修改同一累计字段的原子合并。每行最多 100 次保存，明细最多 70,000 字符；达到上限时停止同步并保留本地记录。保持原存储目录和存储键；回退旧可执行文件不会删除历史，新版待同步记录应先在新版完成同步。

固定官方接口证据与本机验收见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## preview.18 跨电脑成果

原表增加文本列“跨端专注记录”，保存不可变的完整专注快照。启动、保存与手动同步按 UUID 上传/下载合并。旧番茄行补传只改此列，不重放分钟与完成写入；旧会话通过原会话表核验后，快照补到关联原番茄行。原行已删除或内容冲突时提示处理，不悄悄新建替代行。未记账的本地自由记录先走原自由番茄流程，再补快照。

每行最多 100 条快照、70,000 字符；超过时保留本地并提示。旧台账没有快照时不猜完成数，需要在保留原历史的电脑运行新版。第一次补传前自动备份本地状态。任务、分钟和已完成继续使用原番茄表；App 农场/月历使用完整快照。倒计时不会跨电脑迁移。
