# 科学专注浏览器配套（Windows Edge）

ActivityWatch继续拥有唯一网站时间统计；此配套只接收农场当前干预策略和提醒投影，不另算网站时间，不上传网址、标题、Cookie或任务。

在农场“科学专注 → 设置策略”选择时间镜子、暂停、冷静、额度锁定挡。默认为暂停挡、冷静时间2分钟、浏览时原屏幕置顶。镜子挡只显示；暂停挡每次新的提醒暂停当前活动或有声的目标标签页；冷静挡暂停后等待设定时间再继续；额度挡用完后限制两站点至本地次日。督促关闭、App失联或心跳过期解除限制；不是操作系统不可绕过的封禁。

首次配套：先手动安装本次App更新，在设置策略点击“安装／更新浏览器配套”。App复制自带扩展到自己的用户目录，只注册自己的HKCU NativeMessaging项，打开扩展文件夹。然后在Edge `edge://extensions`打开开发人员模式，点击“加载解压缩的扩展”，选择刚打开的文件夹。扩展连接后农场悬浮监测点和设置页显示已连接；暂停回执另外显示实际暂停播放器数。未连接或计数0不代表视频已被暂停。没有后台自动安装扩展、没有操作个人浏览历史。

首次点击提示“无法核对浏览器注册权限”时，先更新到preview90或以后再点同一按钮。89版将中文reg.exe的OEM输出当UTF8，可能把尚不存在的注册项误报为权限问题；90用Windows内置RegistryKey接口和UTF8结构化结果区分缺失/拒绝，并保留中文路径。正常当前用户安装无需管理员，也不需要修改系统权限。注册检查只在点击安装/更新按钮时运行，不增加监测的后台进程或逐秒I/O。

配套更新：安装App更新后再次点击同一配套按钮，Edge扩展页面点击配套的重新加载。其他电脑同样各首次确认一次。当前API协议v1、扩展版本1.0.1，manifest公开key仅固定项目扩展ID，没有保存私钥。

冷静恢复：关闭督促、临时失联或心跳失效仍立即解除页面限制，但保留当前浏览器会话内的原冷静截止时间；同日恢复连接/督促后继续剩余时间，不重新罚满一次。服务worker会话恢复同义；原截止已经过去则旧提醒不再重放，新提醒仍正常生效。切换干预模式或跨日取消旧冷静期，额度锁定的截止不能带入冷静档。没有新增轮询/定时器或逐秒写盘；App更新不会自动替换已加载的扩展，须按上述配套更新步骤重新加载。

扩展的所有激活/安装/启动连接入口共用一次session恢复门禁，恢复完成前不处理原生策略或写新控制状态，避免迟到读取覆盖新状态及重罚。恢复读取失败时不连接、不施加限制、不自动重试；控制台仅一次简短提示，用户重新加载扩展后重试。

官方薄适配：Electron34.5.8 `showInactive`/`moveTop`/`setAlwaysOnTop`让农场保持位置、大小；提醒窗口`show`/`focus`只在新阈值取焦点，不逐秒争抢。MV3只授权bilibili.com和xiaohongshu.com及子域，NativeMessaging主机只接受固定extension origin。微软公开协议规定UTF8 JSON前置4字节本机字节序长度；本模块额外限制4096字节、只接受status和匹配当前提醒的receipt。主机用App内置Node20.19.1，无Python/额外服务/网络监听/浏览器调试端口；只有扩展连接才运行一个消息主机，每5秒沿已有AW心跳读小型投影，没有每秒写盘。浏览器DOM play事件只在冷静/额度限制期间暂停；一个短期页面计时器显示等待，失效后清理。日期切换和掉线均释放。

本机边界：投影和回执是App用户目录内固定文件，不是第二任务或统计真相源；只包含策略、过期时间、提醒key及暂停数量，不接受客户端传入路径/命令。不提供网络服务或Hermes访问此浏览器控制通道。当前部署范围Windows当前用户；初次实际Edge扩展连接与暂停效果须在用户确认加载后验收，合成静默链路不能冒充已控制个人浏览器。

专注修正：边界扩缩保留旧暂停的实际位置、扣新时段与暂停的交集，新增部分可手动计入；原完整区间等长移动保留相对暂停。没有暂停明细的旧记录保留暂停总额，不猜位置；番茄数独立。原数据未迁移。超额后圆环显示累计时分秒和超额时分秒，继续计时；监测失效不凭空续秒。

关闭督促或在Edge禁用配套即可停止干预；原AW记录与专注数据继续可用。配套注册属于本App用户目录，不覆盖同名异来源注册。回滚发布使用新版本，不替换旧tag或资产。
