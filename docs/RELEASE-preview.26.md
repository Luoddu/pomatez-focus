# 番茄农场 preview.26

本版统一 preview.24 的公开源码与 preview.25 的本地新增功能。

- 保留竖屏适配、星期标签、每日番茄合计和今日空白提示。
- 加入番茄到点/休息结束提示音，设置中可关闭。
- 生成今日番茄显示真实阶段进度；“近日行动已勾选”或“计划日为今天”均可纳入。
- 收获按实际专注日期归属；原表回写、自由番茄、手动确认、跨机成果共享保留。
- 开发打包新增实时远端基线检查、源码/构建 SHA 校验与非强制推送流程，防止版本号升高但功能漏合。

Windows x64：下载 setup.exe 安装版或 portable.exe 便携版。正常退出旧版后运行新版，沿用原应用数据目录、飞书配置与历史记录。本次没有数据迁移，不需要复制凭证文件。

验收：113 项逻辑/模拟接口、21 项桌面、12 项横竖屏、69 项界面流程通过；跨机三进程共享、原行/自由番茄重试和更新校验负例通过。详细证据见 docs/ACCEPTANCE-integration.md。

随包提供 SHA256SUMS.txt；包内 source-version.json 可追溯源码 commit。仅验证 Windows x64，仍是未签名预览版。
