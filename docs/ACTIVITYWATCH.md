# 科学休息

番茄农场和 ActivityWatch 独立运行。农场主进程只读取 `http://127.0.0.1:5600/api/0` 的官方 buckets、events 和 query 接口，轮询间隔30秒，失败逐步退避至5分钟；恢复系统后重新读取。浏览器采集心跳也有延迟，因此显示值和提醒不是秒级计时。

首次使用：启动 ActivityWatch，Edge 安装官方 Web Watcher，选项 Browser=Edge、Hostname保持本机名并Save。AW本机窗口/AFK采集器及Edge扩展需要同时运行。农场月历上方会显示“科学休息”；不必打开AW网页。正常农场启动自动开始取数，关闭到托盘继续，明确退出农场后停止提醒；AW继续独立采集。自动开机采集由AW自身启动配置负责，农场不额外建立系统服务或启动项。

默认每日共享60分钟摸鱼额度，督促开启。B站和小红书所有用途均计入；在卡片内设置5–480分钟，按5分钟调整。更改额度或重新开启督促会把已有用量作为提醒基线，之后再累计跨过新的5分钟档才提醒；圆环立即反映新额度。

计数使用网站网址，不依赖视频窗口标题：目标站点的当前标签页与Edge前台窗口相交，再与非空闲或该前台标签页有声音的时段相交。有声视频即使不操作鼠标键盘也能计入；切到其他应用的后台播放不计。已录得重叠区间合并，按本地自然日及小时边界切分。采集间隙不补造。不同Edge窗口的关联采用官方Watcher当前活动窗口/标签页机制。

“查看统计”在卡片原位置显示今日/近7天小时分布；可展开浏览时段，内容在固定卡片内部滚动。近7天属于所选日期范围，如果扩展刚安装，会显示采集起始日期，不能当作完整7天样本。

用尽额度后，每新增5分钟已记录的浏览时间弹一次。离开网站时不因墙钟经过而追加。重启保留已提醒档位；重连合并错过的档位为一条提醒。弹窗仅有标题、一行提示与两个按钮：去睡觉暂停当前计时并隐藏窗口，不操作系统睡眠；开始下一个番茄复用当前选择或现有任务流，已有番茄时返回/恢复它，待确认时仍需用户完成确认。

断连或任一采集器超过3分钟没有新记录时，显示采集中断，保留同一天的最后用量并暂停弹窗；不是显示成零。午夜丢弃上一日显示，失败退避也不会越过午夜。设置或提醒状态写盘失败时暂停督促；正常统计仍可显示，重新保存设置恢复。

原始网址、标题留在ActivityWatch；农场不保存浏览历史副本，不上传这项数据。农场用户目录的 `aw-rest-settings.json` 只保存额度、开关、提醒档位及最后的每日聚合数值。预加载桥只传两个站点的时间、小时分布与时段，不接收任意地址或查询脚本。
