# 科学休息

番茄农场和 ActivityWatch 独立运行。农场主进程只读取 `http://127.0.0.1:5600/api/0` 的官方 buckets、events 和 query 接口，轮询间隔30秒，失败逐步退避至5分钟；恢复系统后重新读取。浏览器采集心跳也有延迟，因此显示值和提醒不是秒级计时。

首次使用：启动 ActivityWatch，Edge 安装官方 Web Watcher，选项 Browser=Edge、Hostname保持本机名并Save。AW本机窗口/AFK采集器及Edge扩展需要同时运行。农场月历上方会显示“科学休息”；不必打开AW网页。正常农场启动自动开始取数，关闭到托盘继续，明确退出农场后停止提醒；AW继续独立采集。自动开机采集由AW自身启动配置负责，农场不额外建立系统服务或启动项。

默认每日番茄目标12个、提醒间隔5分钟、共享摸鱼额度60分钟，督促开启。B站和小红书所有用途均计入。在卡片内点击“设置策略”可调整三项：番茄目标0–60个（0表示仅按额度提醒）、提醒间隔1–60分钟、每日额度5–480分钟（按5分钟调整）。更改策略或重新开启督促会把已有用量作为提醒基线，不补弹过去的提醒；圆环立即反映新额度。设置保存在本机，重启后恢复。

计数使用网站网址，不依赖视频窗口标题：目标站点的当前标签页与Edge前台窗口相交，再与非空闲或该前台标签页有声音的时段相交。有声视频即使不操作鼠标键盘也能计入；切到其他应用的后台播放不计。已录得重叠区间合并，按本地自然日及小时边界切分。采集间隙不补造。不同Edge窗口的关联采用官方Watcher当前活动窗口/标签页机制。

“查看统计”在卡片原位置显示今日/近7天小时分布；可展开浏览时段，内容在固定卡片内部滚动。近7天属于所选日期范围，如果扩展刚安装，会显示采集起始日期，不能当作完整7天样本。

当天未达番茄目标时，B站＋小红书合并每累计观看一个提醒间隔督促一次，尚未用完额度也督促。默认即完成12个前，在5、10、15…分钟提醒。达到自定目标后，额度内停止这项督促；超过每日额度时立即提醒，之后每新增一个提醒间隔继续提醒。两个条件同时命中只显示一条。这里“立即”指采集与农场下一次成功更新，仍有前述轮询延迟，不是秒级弹窗，也不会阻止打开网站。

完成数直接使用现有已确认记录（saved），按本地开始日期计算，与月历同口径；未同步到飞书的本地已确认记录也算，正在计时和待确认不算。确认、补记、修改和跨端历史合并都会更新当天进度，不建立第二套番茄历史；达到目标时清除待显示的额度内督促，超额提醒仍保留。修改完成数回到目标以下不倒放已观察的浏览档位，只提醒新增档位。启动时尚未收到当日完成数则等待；总额度保护仍可工作。

离开网站时不因墙钟经过而追加。重启保留已提醒档位；合法旧账本迁移以上次同日用量作为基线，不补弹过去的早期督促；重连合并错过的档位为一条提醒。弹窗仅有标题、一行提示与两个按钮：去睡觉暂停当前专注计时并隐藏窗口，不操作系统睡眠，也不改已有的休息倒计时；开始下一个番茄复用当前选择或现有任务流，已有番茄时返回/恢复它，待确认时仍需用户完成确认。

桌面版督促使用独立置顶窗口，盖在普通Edge/视频窗口前方；农场隐藏到托盘或最小化时也能出现，不需要打开农场。提醒在鼠标所在屏幕的工作区居中，不把整个农场置顶，不自动抢键盘焦点。仅保留标题、一行说明和两个按钮；点“去睡觉”暂停专注并关闭提醒，点“开始下一个番茄”关闭提醒并回到农场。聚焦提醒后Alt+F4可关闭当前提醒，继续浏览到下一档位仍会再提醒。普通全屏视频沿用系统原生置顶机制；安全桌面及系统独占界面不属于普通浏览器覆盖范围。

断连或任一采集器超过3分钟没有新记录时，显示采集中断，保留同一天的最后用量并销毁提醒；不是显示成零。关闭督促、系统暂停、主渲染器重载或退出时也清理提醒。午夜丢弃上一日显示，失败退避也不会越过午夜。设置或提醒状态写盘失败时暂停督促；正常统计仍可显示，重新保存设置恢复。

原始网址、标题留在ActivityWatch；农场不保存浏览历史副本，不上传这项数据。农场用户目录的 `aw-rest-settings.json` 只保存三项策略、开关、提醒档位及最后的每日聚合数值。旧版本没有番茄目标和提醒间隔时，自动采用12个和5分钟，并保留合法的既有额度；同日旧用量不补弹。预加载桥只传两个站点的时间、小时分布与时段，不接收任意地址或查询脚本。
