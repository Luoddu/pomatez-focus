# 番茄农场 0.1.0-preview.17

Windows x64 桌面便携预览版。下载 `Pomatez-Focus-v0.1.0-preview.17-win-x64-portable.exe` 后直接运行；无需从源码编译。`Source code` 是开发者使用的源码压缩包，不是应用程序。

## 本版功能

- 四象限任务板，选择具体番茄序号，查看任务收获进度。
- 圆环计时、暂停继续、额外时间确认和放弃记录；紧凑小窗可置顶。
- 飞书今日番茄读取与生成，实际分钟、专注日期和时段写回原番茄表。
- 自由番茄、手动补记；记录旁可手动重试同步，失败保留本地。
- 收获农场、番茄月历与按日期排列的专注记录。

## 使用与升级

旧用户退出旧版后启动此文件，沿用原应用数据目录和飞书设置。请勿同时运行多个版本。新用户可先使用本地自由专注，再从右上角设置连接飞书。

本包从 GitHub 已脱敏的 preview.17 源码打包；不含开发者任务、账号配置或个人专注记录。附 SHA256SUMS.txt，可用 PowerShell `Get-FileHash -Algorithm SHA256 <文件路径>` 核对。

## 验证与边界

源码构建、73 项逻辑/模拟接口测试、21 项桌面检查、4 项手动同步检查及进程重启检查通过；本次额外校验打包内容、MIT 许可证与隐藏便携启动。

仅验证 Windows x64，属于未签名预览版；未提供多设备并发合并。飞书连接需要自己的应用与表格权限。原表累计分钟达到目标可完成当前行；确认多个番茄的分钟仍保存在所选行。更多说明见仓库 README 和 docs/FEISHU.md。
