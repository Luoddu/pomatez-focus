# 番茄农场 preview.44

公开源码 `51461998db26c2043f4c5321ecbf959448141f25`（codex/feishu-focus），
在 preview.43 之上叠加统计翻页、热力图转置、成就分级与节气动物。

- 专注统计自由翻页：`stats.ts` 新增 `shiftRange`（以区间中点为锚，避免月末跨档漂移）与 `isCurrentRange`；周/月/季/年四个区间都支持 ‹ › 前后翻页，离开本期时区间标签旁出现「回到本周/月/季/年」提示、点标签一键归位，「下一区间」在本期自动禁用。
- 时段热力图转置为周历式竖排：列=周一~周日、行=0–24 点每半小时一格（7×48），时间自上而下流动，左列整点刻度每 2 小时标注；仅当前周视图给「此刻」格描边高亮。
- 柱状图成就分级：废弃"只有历史最高柱是金色"——每天 1–4 个常规番茄红、5–9 个深红「小丰收」、≥10 个金色「大丰收」（`harvestTier` 分级），附图例；持久战每天都有可达成的目标。
- 农场节气动物（北半球中原物候，与 24 节气同源）：猫头鹰夜间 19:30–5:30 栖上栅栏守田、周期性眨眼；大雁秋天南飞、雨水「鸿雁来」起北归（人字雁阵 60s 横越天空，春北归用反向播放区分方向）；萤火虫只在夏夜、蝴蝶只在春秋白天出没；全部动画纳入 prefers-reduced-motion。
- 四象限任务行：「已收 x/y」进度格从行尾右侧移到任务名下方、红色番茄 chips 上方，阅读顺序变成 任务名 → 进度 → 筹码。
- 打包备注：本轮 `dist/` 被本机 Kimi 桌面进程持锁，构建输出落在备用目录 `dist-preview44/`（已加入 .gitignore），发布资产与 preview.yml 均取自该目录。
