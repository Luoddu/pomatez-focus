# 番茄农场更新记录

## 0.1.0-preview.19

- 兼容早期专注记录的空关联 ID，修复“跨端任务标识无效”导致旧成果无法共享。
- 保留旧快照表示，重复同步不冲突、不重复累计时长或番茄。
- 原飞书番茄行不存在时显示具体恢复提示，继续保留本机记录，不新建替代行。

## 0.1.0-preview.18

- 多台电脑共享已保存记录、农场和月历，当前倒计时独立。
- 原表新增“跨端专注记录”，完整保留用户确认番茄数。
- 历史先备份再补传，不重复累计已同步分钟或完成。
- 手动同步兼顾上传和下载，无待上传时仍可刷新。
- 首版按轮流使用、换机前同步完成验收。


## 0.1.0-preview.17（Windows 便携预览版）

相对最初 preview.1：

- 使用四象限任务板，展示具体番茄序号与收获进度。
- 飞书配置收纳到设置；增加原番茄表的实际分钟、日期、时段与完成状态回写。
- 自由番茄、补记、今日计划生成与数量调整。
- 农场、番茄月历与按日期分组的专注记录。
- 原生窗口控件，小窗置顶与展开窗口切换；保留暂停恢复、超时确认、放弃与导出。
- 补记旁增加手动同步、待同步数量和忙碌状态，失败保留本地记录。
- 公开截图遮盖任务名称，演示数据使用通用任务。

源码与 Windows x64 便携包同步发布。下载新版请访问 [preview.17 Release](https://github.com/Luoddu/pomatez-focus/releases/tag/v0.1.0-preview.17)。
