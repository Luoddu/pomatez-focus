# 番茄农场更新记录

## 未发布（农场体验增强）

- 丰收筐重做：果堆随累计收获逐层长高（上限 21 颗六层堆尖），每收一颗新番茄从顶部弹跳入筐（既有果实不重播）；累计 30/100 颗时两侧各多出一只小筐，超出堆尖上限显示金色「+N」徽标；50/100/200/300/500/1000 颗在堆尖挂金星级程碑旗。
- 季节时令：农场按北京时间月份换景——春飘花瓣、夏来蜻蜓、秋落红叶、冬落雪且土壤带覆薄雪、稻草人戴上红围巾；只加点景动画，不影响专注；减动效偏好下全部静止。
- 番茄果实：渐变压深到 16% 边缘暗部（保持哑光、无高光点的仓库验收约束），立体感靠渐变压深与每颗果实确定性形态微差呈现。
- 专注记录：同步状态改为圆点徽标（绿=已共享到飞书、橙=待同步/待共享、灰=本地记录），一眼可辨；「修改」入口改为铅笔图标按钮，默认收起、悬浮该行时滑出（触屏与键盘焦点始终可见），列表更干净。
- 概览：今日番茄沿用日合计成就分级（≥5 番茄红、≥10 金色带弹跳）；总番茄新增里程碑进度条与「已达成 N · 距 M 还差 K」提示（10/25/50/100/200/300/500/1000 档，全部达成显示「🏆 丰收传奇」）。
- 新增纯函数与单测：`seasonOfMonth`/`beijingMonth`/`totalMilestone`（11 项断言）；截图脚本 `scripts/shot-seasons.cjs` 支持四季 mock 截取与记录行悬浮验证。
- 全量回归：156 项单元测试通过，98 项界面检查通过（含哑光番茄、堆形确定性、天空实时性）。
