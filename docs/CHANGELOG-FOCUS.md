# Pomatez Focus 修改记录

## 0.1.0-preview.2 — 2026-09-06

- 确认页新增“放弃本次记录”，不保存、不统计、不产生飞书待同步项，保留已有历史。
- 恢复 Windows 原生标题栏和最小化、最大化／还原、关闭控件。
- 展开界面左侧为当前番茄，右侧同时展示今日与累计概览、按日期分组的专注记录。
- 切换置顶不再重置尺寸；小窗展开恢复之前的窗口尺寸，保留最大化状态。
- 延续原有本地数据格式与飞书同步流程，无需迁移记录或重新配置连接。

## 0.1.0-preview.1 — 2026-09-06

- 新增简体中文专注界面、可置顶的独立小窗和本地专注记录。
- 到点后保留额外计时；结束时可包含、排除或修正时间，并手动填写完成数。
- 记录暂停与提前结束；重载及进程重新启动时暂停恢复，排除关闭期间的时间。
- 新增飞书今日计划读取、字段映射、系统加密凭证和会话同步。
- 以稳定会话 ID + 飞书 client_token + 回读校验处理重试，避免重复写入。
- 新增飞书看板字段与配置指南；当前版本尚未自动配置图表。
- 保持上游 Electron/React 构建基线，新增隐藏窗口测试与 Windows 便携包构建入口。
- 使用独立应用 ID/用户目录，关闭上游自动更新、Discord RPC 和自动开发工具启动。

预览版的已知限制见 README。上游历史修改记录仍保留在根目录 CHANGELOG.md。
