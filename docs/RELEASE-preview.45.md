# 番茄农场 preview.45

公开源码 `427a32df2eb3e784c73955a6603ade11804152d8`（codex/feishu-focus），
在 preview.44 之上做统计页改版与计时页极简。

- 时段热力：48 格扁长半小时格 → 7×24 小时格（`hourlyRows` 纯函数合并，数值守恒有单测），格子加高至 12px、圆角加大，不再扁长；悬浮仍显示该小时收获。
- 柱状图成就色连续化：撤掉文字图例——`barTone(count)` 纯函数让 1–9 个在番茄红谱系内越收越深、≥10 个进入金色谱系且数量越多金色越亮、光晕越大（rgba 透明度与光晕半径随数量连续增强），颜色自己说话。
- 隐私安全：任务排行下线（截图分享会暴露任务名），替换为「象限分布」（五象限投入番茄数与占比）；新增「时段偏好」板块（🌙 深夜 / 🌅 上午 / ☀️ 下午 / 🌆 晚间，`daypartSplit` 纯函数按热力矩阵汇总）；与「高光时刻」组成三卡行，整页一屏基本看完。
- 「已收 x/y」回到任务行尾右侧：文字在上、红色记数格在下竖排，不再压住番茄筹码。
- 计时页极简：去掉「额外时间 · 等待你确认」与「本轮分钟 / 已积累 / 多计时」三条 chips（及样式）；「已专注 X」改为攒满一个番茄（elapsed ≥ planned）才亮出。
- 农场动物减速：蝴蝶 7s→13s、大雁 60s→110s，飞行更从容。
- 工程备注：dist 仍被本机 Kimi 桌面进程持锁，打包输出在 dist-preview45b；curl schannel 栈在本机代理下反复卡死大文件 POST，最终经 SOCKS5（7891）通道完成上传，新增 `tests/upload-asset-desktop.cjs`（Electron/Chromium 网络栈）作为备用上传通道。

Windows x64：下载 setup.exe 安装版或 portable.exe 便携版。正常退出旧版后运行新版，沿用原应用数据目录、飞书配置与历史记录。本次没有数据迁移，不需要复制凭证文件。
