# 番茄农场 preview.19：旧记录共享兼容修复

修复 preview.18 迁移早期专注记录时出现“跨端任务标识无效”的问题。旧版使用空字符串表示尚未读取到的关联任务 ID；新版保持该表示并允许同步，仍严格校验非空 ID。

已成功共享的记录不重复计数或累计时长。如果原飞书番茄行不存在，会提示恢复原行后重试，并保留本地历史；此版本不会自动创建替代行。

主力机从托盘退出旧版，再运行新版并点击“手动同步”。其他电脑也使用同版并连接同一张飞书表。当前计时不跨电脑接力。

86 项逻辑/模拟测试通过，包含旧空关联迁移、重复同步和原行缺失负例。真实历史只读核对已区分格式问题与原行缺失；实际补传由新版运行时执行。
