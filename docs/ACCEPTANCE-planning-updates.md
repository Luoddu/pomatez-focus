## 原因与修改

原 `collectTaskPlans` 仅认任务表计划日等于今天，`generateToday` 还强制要求任务日期字段。用户现在以“近日行动”复选框选择任务、任务计划日留空，导致候选为 0；UI 又把创建 0 一律解释成已齐全。现优先使用复选框模式，按今日数量生成，排除完成/放弃；没有该字段时保留日期模式。原番茄表计划日仍写今天。区分无候选与候选已齐全。

更新复用固定 `electron-updater 6.8.3` 的 `NsisUpdater`，安装构建使用 `electron-builder 25.1.8`，运行时 `Electron 34.5.8`。正式来源固定为项目 GitHub preview 通道；没有可配置的任意下载 URL 或 renderer shell 执行。检查/下载由用户点击，下载校验后由官方 NSIS 安装重启；未结束的 active/paused/review 会话阻止安装，空闲安装前备份记录。退出不自动安装。
