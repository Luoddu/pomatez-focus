# 番茄农场 preview.18：三台电脑，共享一份成果

下载 Windows x64 portable EXE 后直接运行。主力机先升级并同步，再让其他电脑安装同版、连接同一张飞书表。

- 专注记录、用户确认番茄数、农场与月历跨电脑共享。
- 启动、保存与手动同步均可上传/下载；同一记录不重复计数。
- 第一次补传前自动备份本机历史；原飞书番茄表增加一个可隐藏的“跨端专注记录”文本列。
- 补齐历史不重复累计已同步分钟或勾选完成。
- 本地自由记录在连接飞书后进入自由番茄流程；断网、原行缺失或冲突时保留并提示。

倒计时只留在当前电脑，不做接力。首版支持轮流使用，换机前同步完成，不支持同时多机修改同一番茄的原子合并。每台电脑分别配置飞书，不复制运行目录或加密凭证。

通过 83 项逻辑/模拟测试、通用桌面检查、手动同步检查和三个独立 Electron 进程的 A→B→A 往返验证，当前计时保持不变。实际主力机历史补传在首次启动新版时执行；其他两台电脑的安装仍需在各自电脑进行。

Windows x64 未签名预览版；附 SHA256SUMS.txt。基于 Pomatez v1.11.0，MIT 许可证。详情见 README、docs/FEISHU.md 和 docs/ACCEPTANCE-multidevice.md。
