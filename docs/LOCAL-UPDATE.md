# 本机安装更新与分段番茄

结束确认页的紫色“切断本次”保存本段时长，完成数为0，返回看板后可做其他任务。同一个番茄以稳定planId／本地ID关联，浅底虚线和悬浮信息显示已投入与剩余；再次开始扣除已确认投入。例如先14分20秒、后10分40秒，时间合计25分钟，完成数合计1。已同步和待同步片段按原session ID／原分钟台账去重，不重复记时。

自由番茄切断后，在开始区出现“接续自由番茄 · 剩余…”；该入口保留原身份和已同步生成的planId，完成后消失。普通“开始自由专注”仍创建全新番茄。切断不可用于零时长或已完成的整颗番茄；原“记录番茄”“放弃本次”“返回继续计时”保留。

## 本机交付（Windows当前用户）

开发者完成固定源码构建、NSIS包源核验及独立复核后，将同一份本地安装包准备给本机App，再发布GitHub；本机不必从GitHub再下载一份。现有远端“检查更新”继续可用。首次旧版没有新入口时，需经用户同意，用本地NSIS安装一次；不在运行中替换ASAR。

```powershell
node scripts/stage-local-update.cjs artifacts/release104
```

输入文件夹须包含同源的`source-version.json`（dirty=false）、`preview.yml`及其唯一NSIS安装包。helper核对固定文件名、版本、来源commit、大小、SHA512后，原子提交到当前用户App数据目录的`local-update`。相同版本/相同字节重复执行不重复复制；同版本不同来源/内容、已有异来源目录、UNC、路径逃逸或链接拒绝，不覆盖用户数据。可选第二参数只用于授权的隔离测试profile。

在App设置中看到“本机已准备…”，点击“重启以加载更新”。它先暂停并保存当前计时、写入一致性快照备份，再使用原electron-updater的generic feed、SHA512校验和NSIS安装重启。旧有投入、记录和暂停/确认状态保留；关闭期间不计时。没有新本地包时按钮为“重启app”，同样先保存并备份。备份或校验失败不退出，重复请求不会重复重启。

本地传输只在点击时于原主进程临时监听127.0.0.1随机端口，随机路径仅供固定feed和固定包的GET，完成即关闭；不接收外部路径、URL、命令，不增加常驻服务或后台轮询。安装器走公开`setFeedURL/checkForUpdates/downloadUpdate/quitAndInstall`，不修改updater受保护缓存。不会自动点击重启、改变真实飞书/浏览器配置。开发者仍须发布五个GitHub资产，供其他电脑手动更新和其他Codex继续维护源码。

## 验收与回滚

见`docs/ACCEPTANCE-P0-POMO-067.md`及执行卡。部署前保留原本机安装器与关闭后的记录副本；失败可回装旧版本，0完成片段仍是原记录格式，不迁移或删除数据。准备好的更新包只是可校验副本，不是新的记录真相源。
