# 🍅 番茄农场 · Pomatez Focus

**把今天的任务变成番茄，把每一次专注种进自己的农场。**

一个面向 Windows 的桌面番茄钟：从四象限中选择任务，用可置顶的小窗专注，结束后确认实际投入，并把结果写回飞书的今日番茄。支持自由专注、手动补记、专注月历和随收获生长的农场。

基于 [Pomatez](https://github.com/zidoro/pomatez) v1.11.0 薄改，保留上游 MIT 许可证与历史。

## 功能

| 功能 | 使用体验 |
| --- | --- |
| 四象限选任务 | 保留重要／紧急标签，每个任务可选择具体的第 N 个番茄，显示已收获进度 |
| 桌面专注小窗 | 圆环计时，暂停、继续、提前结束；小窗可置顶，大窗口可正常切换应用 |
| 超时确认 | 到点后继续记录额外时间，结束时由你决定是否计入，以及保留多少实际分钟 |
| 自由番茄 | 不选任务也能开始专注；绑定飞书后，确认的自由番茄进入原番茄表 |
| 补记与重试 | 补记已经做过的工作；“补记”旁显示手动同步按钮、待同步条数和执行状态 |
| 飞书计划联动 | 读取／生成今日番茄，调整计划数量，回写专注数据和完成状态 |
| 农场与月历 | 专注记录汇总为今日／累计收获和时长；农场随本周收获生长，天空随时间变化 |
| 三台电脑轮用 | 连接同一飞书表，合并已保存成果；倒计时留在当前电脑 |
| 本地记录与导出 | 先保存本地，支持 JSON 导出；中断后恢复为暂停状态 |

## 开始使用

1. 下载上方 Windows x64 portable `.exe` 并直接运行，无须部署服务器。GitHub 的 `Source code` 压缩包供开发者使用。
2. 在四象限中选一个番茄，再点击“开始专注”。不选择任务时，按钮为“开始自由专注”。
3. 需要离开时暂停，回来继续。点击结束后核对实际分钟和完成番茄数；也可返回计时继续工作。
4. 点击“记录番茄”保存；不认可这次专注时选择放弃，不新增记录。
5. 如果显示“待同步飞书”，点击专注记录标题旁的“手动同步”。同步中按钮禁用，失败会显示原因，记录仍保留本地。

右上角齿轮收纳飞书设置。小窗支持置顶；展开窗口自动解除置顶，避免遮挡其他应用。关闭窗口会收起到托盘，彻底退出请使用托盘菜单。

## 飞书联动

使用企业自建应用连接现有多维表格，无须个人 OAuth，也不向聊天会话发送消息。

```text
飞书任务／今日番茄 → 四象限选任务 → 专注／暂停／继续
                                    ↓
                         确认分钟与番茄数 → 本地保存
                                    ↓
                     回写原番茄表 → 刷新进度与记录
```

- **读取计划**：默认使用“专注记录”表的“计划日”“任务”“已完成”；四象限从关联任务表识别。生成今日番茄需要关联任务表中的“今日计划番茄数”（兼容“今日番茄数”），不是从任务标题猜测数量。
- **回写原行**：累计“实际分钟”，保存“专注日期”“专注时间段”，通过“专注同步明细”记录已应用的会话，防止重复累计。同一番茄分几次专注也能累计。
- **确认完成数**：当前版允许确认多个番茄；按所选任务、日期和连续序号回写对应完成状态，缺失序号可补建。部分行写入失败会单独提示，计时到点本身不发送写入；确认保存后，该行累计时长达到目标也会触发已完成。
- **自由专注**：连接飞书后新开始的自由番茄，在确认时于原表新增一行，并复用“自由番茄”关联任务。
- **补记区别**：补记选择飞书任务时进入同步队列；补记自由专注和本地记录，连接飞书后通过原表自由番茄流程共享；未连接时保留本地。
- **失败处理**：断网后保留待同步；手动重试复用同一条记录。原行内容冲突、关联改变或权限不足时提示核对，不靠不断重试掩盖错误。

旧会话保留原记账路径；新版核对后把完整快照补到原番茄表，不重复累计分钟。共享成功显示“已共享到飞书”。飞书仪表盘可以使用原表累计分钟与完成状态，图表仍需在飞书中配置。

## 换电脑使用

三台 Windows 电脑安装同一个 preview.19 版本，分别连接同一张飞书番茄表。先在保留完整历史的主力电脑打开新版并同步，再打开其他电脑。

- 第一次补传前自动备份到应用数据目录的 backups/before-cloud-history-v1.json，包含本机记录与当前计时。
- 原表新增可隐藏文本列“跨端专注记录”，保存任务/象限、时间段和用户确认番茄数；不要手工改动其 JSON。
- 打开 App 会同步，手动同步兼顾上传和下载；没有待上传记录时仍可获取其他电脑成果。
- 按 UUID 合并；重复同步不重复计数。农场、月历和统计使用合并后的记录。
- 断网、内容不一致、缺失原行或容量超限时，保留原数据并提示。旧台账缺少完整快照时，请在原电脑补齐，不从 0/1 达标标记猜完成数。
- 当前倒计时不上传、不接力。首版仅支持轮流使用，换机前同步完成。
- 每台电脑自行配置一次连接，不通过网盘复制运行目录或加密凭证。

## 数据与边界

- 凭证通过 Electron `safeStorage` 使用系统加密，留在本机；记录也保存在本机应用数据目录。版本更新沿用原有存储键。
- 不启用遥测、自动更新、开机启动或对外监听端口。支持单人多台电脑轮流使用；换机前同步完成，不支持同时修改同一番茄的原子合并。
- 暂停与关闭期间不自动计时；无法自动判断人是否真的在专注，超时是否有效仍由用户确认。
- 原表“实际分钟”是该行累计值，“专注日期”是最近一次专注开始时间；不能直接把跨多天的整行累计当作逐日分摊。精确会话可查看 App 记录或导出。
- Windows 便携包未签名。上游保留的 macOS、Linux、Tauri 文件不代表本分支已完成这些平台验证。
- 当前沿用 Electron 34.5.8 工具链；运行时升级、长期可靠性和多平台支持仍需后续工作。

## 本地开发

工具链：Node.js 24、Yarn classic 1.22.22、Electron 34.5.8、React／TypeScript。使用锁文件安装依赖。

```sh
yarn install --frozen-lockfile --ignore-scripts
node node_modules/electron/install.js
node scripts/build-focus.cjs

# 逻辑与飞书模拟接口
node --test tests/session.test.mjs tests/feishu.test.cjs tests/plan.test.cjs
node --test tests/generate.test.cjs tests/week.test.mjs tests/history.test.cjs tests/cloud.test.mjs
node tests/cloud-desktop.cjs

# 通用桌面检查与 Windows portable 构建
node scripts/test-desktop.cjs
node scripts/package-focus.cjs
```

输出位于 `app/electron/dist/`。专项桌面脚本见 `tests/manual-sync-desktop.cjs` 等，使用隔离配置与隐藏窗口；它们的模拟接口测试不代表真实账户同步已经成功。版本与具体检查结果见 [验收记录](docs/ACCEPTANCE.md)。
